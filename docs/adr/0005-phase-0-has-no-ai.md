# Phase 0 ships without AI, although Fried's original has some

Fried's Write_On includes AI: `??` and Ctrl+Shift+G ask for alternatives, and the Lab marks and trims. We leave all of it out of Phase 0 on purpose. The roadmap's first gate asks whether alternatives, Ghost and Overflow alone make the writer prefer this editor; adding AI first would blur that test. AI alternatives and the Lab arrive in Phase 1, under the rule that machine words enter only as one more variant, never as the active text.
